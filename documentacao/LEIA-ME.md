# Fluxo para Instagram — prévia local

Abra [`index.html`](../index.html) no navegador para cadastrar perfis, criar regras e simular interações. Os dados são salvos no armazenamento local do navegador e podem ser perdidos se os dados do navegador forem apagados.

Esta prévia não conecta contas, não monitora comentários ou directs, não envia mensagens e não é um serviço de automação em produção. Regras salvas aqui representam apenas a configuração proposta; será necessário implementá-las no servidor e conectá-las à API da Meta.

Para operar com contas reais, ainda serão necessários um aplicativo Meta, contas profissionais, permissões adequadas, um servidor com endereço HTTPS acessível para webhooks, tratamento e armazenamento seguro dos dados, integração com a API e testes reais. A disponibilidade de permissões e de acesso depende da configuração e das exigências da Meta.

Referência: [documentação oficial da API do Instagram](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api).
